# Scenario records

The API's typed scenario catalog is defined in `backend/app/main.py`. Scenario events are stored in SQLite and captured in experiment exports. Every catalog action explicitly uses `SIMULATED EVENT`; no card creates live RF evidence.

For a supported real topology change, edit the node's actual configuration and restart through Simulation Control. The separate real adapter currently supports one serving cell. Use Overview to pre-authorize designed PCI/EARFCN values and review the subsequent actual observation.
